# Antigravity Skills

Ця папка призначена для збереження скілів (skills) Antigravity для цього проекту.

## Структура скіла

Кожен скіл має бути окремою підпапкою з файлом `SKILL.md`:

```text
.agents/skills/
└── <ім'я-скіла>/
    ├── SKILL.md          # Обов'язково: основний файл з інструкціями та YAML frontmatter
    ├── scripts/          # Опціонально: допоміжні скрипти
    ├── examples/         # Опціонально: приклади використання
    ├── resources/        # Опціонально: шаблони та додаткові файли
    └── references/       # Опціонально: детальна документація
```

## Формат `SKILL.md`

```markdown
---
name: my-custom-skill
description: >-
  Короткий опис того, коли агенту слід використовувати цей скіл (від третьої особи).
  Наприклад: "Використовуйте цей скіл, коли користувач просить розгорнути бекенд або оновити лямбди."
---

# Назва скіла

Опис кроків та інструкції для виконання.
```
